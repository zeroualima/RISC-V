# RISC-V Assembly: Algorithms & Data Structures

This repository contains a comprehensive collection of algorithms and data structures implemented entirely from scratch in **RISC-V Assembly**. It was developed as part of the low-level computer architecture curriculum at ENSIMAG.

The project demonstrates a deep understanding of memory management, register allocation, algorithmic optimization, and hardware-level execution. All modules were rigorously tested and achieved a 100% pass rate through an automated CI/CD evaluation pipeline.

## Key Implementations

### 1. Advanced Data Structures
* **Hash Tables:** Implemented custom hashing, collision handling, dynamic insertion, lookup, and deletion.
* **Binary Search Trees (BST):** Engineered recursive and iteratively optimized (tail-call) search algorithms.
* **Linked Lists:** Built in-place list reversal and memory-efficient list splitting.

### 2. Sorting & Optimization
* **Array Manipulation:** String reversal, sizing, and minimum-value extractions.
* **Gnome Sort (Tri Nain):** Implemented multiple iterations of the Gnome Sort algorithm, culminating in a highly optimized, hyper-efficient version (`tri_nain_superopt`) that competed in a cohort-wide execution-time leaderboard.

### 3. Mathematical & Recursive Functions
* **Algorithmic Math:** Greatest Common Divisor (GCD), Egyptian multiplication, and Fibonacci sequences.
* **Recursion:** Standard and tail-call optimized factorial calculations.

## Technical Highlights
* **Architecture:** RISC-V 
* **Concepts Mastered:** Pointer arithmetic, stack/frame pointer management, calling conventions, tail-call optimization, and algorithmic time-complexity reduction at the assembly level.
